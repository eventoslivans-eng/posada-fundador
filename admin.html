Conecta tu cuenta de GitHub una sola vez. Los cambios que publiques se guardan en tu repositorio y Netlify actualiza la página solo.

  1. En GitHub entra a Settings → Developer settings → Fine-grained tokens y toca Generate new token.
  2. En Repository access elige solo el repositorio de la página.
  3. En Permissions → Contents elige Read and write. Copia el token y pégalo abajo.
